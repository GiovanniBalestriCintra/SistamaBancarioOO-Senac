# 🏦 Sistema Bancário Orientado a Objetos

Projeto acadêmico desenvolvido durante o curso no **SENAC**, com o objetivo de praticar os conceitos de Programação Orientada a Objetos (POO) utilizando C#.

## 📌 Sobre o projeto

O Sistema Bancário Orientado a Objetos é um projeto voltado à aplicação dos fundamentos da programação no desenvolvimento de uma aplicação que representa um sistema bancário.

A proposta é organizar o código de forma estruturada, utilizando os princípios da orientação a objetos para representar entidades e comportamentos relacionados ao contexto bancário.

## 🎯 Objetivos

- Aplicar os conceitos de Programação Orientada a Objetos.
- Praticar o desenvolvimento de aplicações utilizando C#.
- Trabalhar com classes, objetos, atributos e métodos.
- Desenvolver a lógica de um sistema inspirado em operações bancárias.
- Melhorar a organização, a legibilidade e a manutenção do código.

## 🛠️ Tecnologias utilizadas

- **Linguagem:** C#
- **Plataforma:** .NET
- **IDE:** Visual Studio
- **Conceito principal:** Programação Orientada a Objetos (POO)

## ⚙️ Como executar o projeto

### Pré-requisitos

Visual Studio 2022 instalado.
SDK do .NET 8.0 instalado. ``

### Passo a passo

1. Clone este repositório:

   ```bash
   git clone https://github.com/GiovanniBalestriCintra/SistamaBancarioOO-Senac.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd SistamaBancarioOO-Senac
   ```

3. Abra o arquivo `SistamaBancarioOO.sln` no Visual Studio.

4. Aguarde o carregamento dos arquivos e a restauração das dependências.

5. Defina o projeto de inicialização, caso necessário.

6. Execute a aplicação utilizando `F5` ou `Ctrl + F5`.
